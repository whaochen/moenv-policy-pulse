# 本機版精簡設計

## 目標

將 vault 收斂為本機 Windows 工作排程與手動政策研究，移除已停用的 Codex 與 GitHub Actions 排程，並提供最近 30 天政策趨勢。

## 執行邊界

- 保留現有 Windows 工作排程的每日新聞更新與 email。
- 刪除 Codex 的「環境部新聞健康檢查（每10天）」及「每週五 22:00 政策研究排程」。
- 刪除 GitHub Actions workflow 與雲端化操作說明；不嘗試刪除無法從本機 vault 存取的 GitHub 執行歷史。
- 2001-01-01 至 2020-12-31 是固定歷史基線。未經明確要求，手動健康檢查、完整性核對與缺漏補齊只處理 2021-01-01 以後的新聞。

## 導覽與資料設計

- `01_政策議題/政策議題總覽.md` 是唯一的議題目錄；移除 `索引/關鍵字.md` 與其 20 個重複頁。
- 政策研究改為兩段式人工流程：先統整關鍵字，再明確指定題目產出研究。
- 每日 email 報告只包含新聞更新，不再產生研究更新佇列。
- 移除內部研究佇列及空的測試殘留檔案。

## 最近 30 天趨勢

索引器以索引中最新日期為終點，取當日與前 29 日並和前一個 30 天窗口比較。它產生 `02_環境部新聞_可公開/最近30天政策趨勢.md`，提供新聞量、前期比較、每週量、關鍵字排行與代表新聞。訊號只呈現新增、上升、持平或下降，不推論政策因果。

## 驗證

- 使用固定日期資料的單元測試驗證窗口、比較、議題排行及代表新聞連結。
- 驗證每日報告不再建立研究更新佇列。
- 執行完整測試與離線 `--rebuild-indexes`。
