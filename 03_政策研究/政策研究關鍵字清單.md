# 政策研究關鍵字清單

本清單用於人工選題與正式政策研究。沒有自動排程；每次僅在使用者明確指定題目後處理一個議題，完成後應：

1. 依 `moenv-policy-research` 產出正式研究 note。
2. 發布到 `03_政策研究/研究報告/`。
3. 更新本清單的 `status`、`published_note`、`completed_date`。
4. 更新 `03_政策研究/政策研究索引.md` 的最新研究表。

## 狀態定義

| 狀態 | 意義 |
|---|---|
| `published` | 已發布正式研究 note |
| `merged-published` | 已併入另一篇正式研究 note |
| `todo` | 待人工選題研究 |
| `hold` | 暫緩，等待新資料或人工判斷 |

## 手動使用方式

- 先要求「整理政策研究關鍵字」，依新聞量、近 30 天動能與研究缺口檢視候選題目。
- 再要求「啟動政策研究：<題目>」；只有明確指定題目才產出正式研究。
- 若議題涉及現行法規、費率、主管機關、國際制度，執行時必須重新查證官方來源。
- 報告章節固定使用：關鍵字判讀與同義詞、政府正確解釋、本地新聞資料統計、2001年至今政策趨勢、重點新聞索引、法規與制度清單、主管機關與配合機關、國際趨勢與比較、學術式議題分析、未來研究議題與方向。
- 若一個議題可自然併入另一題，先在本清單註記，不直接刪除。

## 選題原則

- `schedule_order` 僅作為人工統整時的建議順序，不會自行觸發研究。
- 優先檢視 `status = todo` 的議題及其近 30 天新聞動能；涉及現行法規、費率、主管機關或國際制度時，研究前必須重新查證官方來源。
