# 環保署發布「違反毒性及關注化學物質管理法行為揭弊者法律扶助辦法」

## 摘要

環保署表示「做對的事，不應該受到欺負」，政府應當揭弊者的後盾並給予法律上的扶助，爰環保署於108年1月16日修正公布之「毒性及關注化學物質管理法」（以下簡稱本法）增訂第54條，並依同條第7項之授權，訂定「違反毒性及關注化學物質管理法行為揭弊者法律扶助辦法」，鼓勵事業內部員工檢舉不法。
