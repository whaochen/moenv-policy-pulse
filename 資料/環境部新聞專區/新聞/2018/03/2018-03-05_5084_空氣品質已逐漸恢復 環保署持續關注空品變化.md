# 空氣品質已逐漸恢復 環保署持續關注空品變化

## 摘要

依據氣象與空氣品質監測資料，預估空氣品質將逐漸轉好，AQI將繼續下降，環保署目前仍維持執行處層級應變工作，地方政府則僅新北市成立地方防制指揮中心，臺北市成立局層級之應變中心；環保署並持續與中央部會與地方政府密切掌握應變措施執行情形及關注空氣品質變化，促使空氣品質改善，請民眾勿過於擔心。
