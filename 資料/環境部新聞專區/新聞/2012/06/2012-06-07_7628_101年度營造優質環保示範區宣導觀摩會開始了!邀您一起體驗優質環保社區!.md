# 101年度營造優質環保示範區宣導觀摩會開始了！邀您一起體驗優質環保社區！

- 類別：飲用水
- 發布單位：毒管處

## 摘要

環保署為提昇全國環境衛生品質，推動營造永續優質環境衛生計畫，補助地方政府營造優質環保示範區，建構永續樂活舒適的優質環境，並規劃今(101)年度於臺北市南港區、臺中市西區及南屯區、臺南市北區、高雄市彌陀區計舉辦計5場次營造優質環保示範區宣導觀摩會，第1場次觀摩會活動訂於6月9日上午8時30分於臺南市北區文元國小旁臨時停車場舉行。
