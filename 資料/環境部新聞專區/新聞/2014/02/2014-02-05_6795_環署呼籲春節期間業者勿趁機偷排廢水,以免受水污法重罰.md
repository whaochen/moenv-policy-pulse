# 環署呼籲春節期間業者勿趁機偷排廢水，以免受水污法重罰

## 摘要

農曆春節期間，家家戶戶忙著大掃除，環保署呼籲工廠，勿心存僥倖利用春節連續假期偷排廢（污）水，如遭查獲偷排廢水，最重可處以停工，切勿以身試法，得不償失。
